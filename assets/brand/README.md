# AnkaLoop brand assets

The SVG files are the editable source of truth. PNG and ICO files are generated from them.

| Asset | Use |
| --- | --- |
| `ankaloop-logo.svg` | Primary square logo on its dark background |
| `ankaloop-mark.svg` | Transparent mark for dark backgrounds |
| `ankaloop-mark-light.svg` | Transparent mark adjusted for light backgrounds |
| `ankaloop-wordmark.svg` | Horizontal README, website, and social header |
| `png/ankaloop-logo-*.png` | Common raster sizes from 32 to 1024 pixels |
| `png/ankaloop-mark-512.png` | Transparent mark for dark backgrounds |
| `png/ankaloop-mark-light-512.png` | Transparent mark for light backgrounds |
| `png/ankaloop-wordmark-1400.png` | Raster horizontal wordmark |
| `favicon.ico` | Multi-resolution 16, 32, and 48 pixel favicon |
| `source/ankaloop-logo-concept.png` | Original generated concept retained for reference |

Primary colors: navy `#020B20`, blue `#1488FF`, royal blue `#0957F5`, and cyan
`#22DFF3`.
